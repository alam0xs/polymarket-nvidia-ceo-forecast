Adaptive volatility quantile forecaster for Polymarket’s Next CEO of NVIDIA? Yes prices: it forecasts each market’s price at every minute of the next 4 hours as five quantiles (5%, 25%, 50%, 75%, 95%), using per-market realised volatility from the last two hours and a drift toward the cross-sectional sum-to-one target.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
